# 03 — Courses and Resources (in order)

> This is the **master list**, in the order you should take things. ⭐ = must do · ○ = optional/alternative · 💲 = paid.
>
> **Don't try to finish every resource on this list.** For each phase, do the ⭐ items and use the rest as references when you get stuck. The real learning happens in the **projects**.

## Budget summary

You can do **this whole plan for free.** If you have a budget, spend it in this order (approximate):

1. *Designing Data-Intensive Applications* (2nd ed.) and *AI Engineering* (Chip Huyen): ~$120 for both. The highest-value purchases.
2. LLM API credits: ~$10–30/month during Phases 3–7. Use cheap models for development and set spending limits.
3. *System Design Interview* Vol. 1 + *ML System Design Interview* + *GenAI System Design Interview*: ~$120.
4. GPU rental for fine-tuning: ~$20–50 total (Colab/Kaggle free tiers can cover most of it).
5. Mock interviews: Exponent or Hello Interview: ~$50–150, in the final 2 months only.
6. Optional: one AWS certification exam: $150.
7. Optional: a domain name for your portfolio: ~$12/year.
